# Travary

Add your bookings and every day of your holiday organises itself.

- `flutter run` uses Firebase: real trips, starting empty.
- `flutter run --dart-define=TRAVARY_BACKEND=demo` starts with sample trips.
- `flutter test` runs the test suite.

See `CLAUDE.md` for the architecture, `docs/PRODUCT_PLAN.md` for the product
plan, and `assets/art/README.md` for adding card artwork.
