## Onboarding: one continuous animated story (done, working)

Walked end to end on the iPhone 17 Pro simulator: Travi rolls into the paper
workshop → the destination folds up behind him → he flicks the dates' tag
(the live countdown tag lands) → opens the folio (forms open out of it; Smart
Import reads on the stage) → shows the saved booking on a card, tosses it
into Day 1 → ID tag (sign-in) → passes (paywall, live RevenueCat prices) →
wave → the folio opens into the trip.

- Logic: `lib/logic/onboarding_films.dart` (`TraviPose`, `traviCuesFor`,
  `traviRoute`), generated `lib/logic/onboarding_film_assets.dart` (never
  hand-edit), `onboarding_journey.dart` (beats and words).
- Player: `lib/design/widgets/travi_player.dart` (animated WebP decoding,
  idles, never cuts a move, dissolves where no film exists). Scene:
  `onboarding_scene.dart` (pop-up stage, `ProofCardWords`). Screen:
  `lib/features/onboarding/onboarding_screen.dart`.
- Tests run with `TraviPlayer.playback = false` (`test/flutter_test_config.dart`).
- Design tools (debug, Profile tab) → **Restart onboarding** replays it from
  the roll-in (`OnboardingStore.restart`).

### The film pipeline

1. Key frames: ChatGPT stills (the owner makes them; free for them) →
   `docs/mockups/onboarding-keyframes-v1/build_keyframes.py` lines them up
   to one camera → `registered/`.
2. Films: the owner's **Scene Studio** (`~/Documents/video_generator`,
   `npm run dev`, port 3717; Seedance 2.0 via Replicate, first + last frame).
   `docs/mockups/onboarding-films-v2/films.py submit|poll|collect <names>`
   (prompts in `shots.json`). **Replicate costs real money**: submit only
   approved shots; a failed submit is recorded `submit_pending`, check the
   Scene Studio job list before `--retry-pending`.
3. `process.py <names>` keys the green, trims, eases ends into the exact key
   frames. `export.py` writes `assets/onboarding/travi/{films,stills}/` and
   the Dart manifest (add new films to its `EXPORT`).
4. Python needs numpy, Pillow, SciPy: make a venv in the scratchpad
   (`python3 -m venv <dir> && <dir>/bin/pip install numpy pillow scipy`).
   ffmpeg can't decode alpha WebP; use `dwebp`/`img2webp`/`webpmux`.

## Next feature: Travi cameos around the app (agreed direction)

Travi appears beyond onboarding as a cameo, not a constant presence:
small, under 1.5 s, tap to dismiss, never delaying content.

| Moment | Travi | Art |
|---|---|---|
| Countdown between trips (`CountdownTripHero`) | Peeks from behind the postcard; tapping the luggage tag gets a reaction by days left: cheer (a month+), packing (~a week), ready (the day before), boarding pass (the day) | New peek set |
| First open of the day | One wave from behind the Today header, then ducks. Only on the countdown and free days | New peek set |
| Free day mid-trip (Today's "A free day" `EmptyState`) | Lounging in a deckchair, idling | New lounge |
| Smart Import anywhere | Reading pose instead of the spinner | Existing (`reading`, `reading-idle`) |
| Empty Trips / "Nothing coming up" | Folio open, "Got a booking for me?" | Existing (`folioOpen`) |
| Errors (import failed, sync failed) | Sheepish oops | Existing still (`oops`) |
| Later: welcome home after a trip | Souvenir | Later (memories/recap) |

Never on tickets, boarding passes, flight status, travel documents, Today
during a busy day, or paywalls outside onboarding. At most one moving cameo
per session; the launch wave at most once a day and not when something is
on within a couple of hours; countdown reactions only on tap; reduced motion
shows stills only.
