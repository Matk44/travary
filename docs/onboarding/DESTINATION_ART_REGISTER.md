## Status and update rules

`needed → generated → review_ready → approved → integrated → published` records image progress. **Prototype ready** is separate from Flutter integration; **brief ready** means the scene/art brief exists, not the image. Generation priority is tracked separately: **primary** country coverage, **reuse** existing exceptions, **deferred** optional specific-place art. The native bundle now integrates the shared assets and two specific-place exceptions listed above; no country stage or downloaded onboarding art pack has been published by this work.

Keep this table and the JSON ledger in sync. For a newly selected city, first check its country stage; do not automatically add a new image requirement. Record selected masters, exact prompt/reference logs, dimensions, geographic scope, integration state and publication evidence. Append meaningful changes to the change log.

Generate complete queues when the owner explicitly requests a batch, as authorized for the 30 city additions on 7 October. Brief additional country stages and shared story assets as needed, using the [generation template and layout contract](../ONBOARDING_DESTINATION_ART.md).
