## Status and update rules

`needed → generated → review_ready → approved → integrated → published` records progress. **Prototype ready** is a separate current state, not proof of Flutter integration. None of the onboarding stages has been integrated or published by this work.

Keep this table and the JSON ledger in sync when a new destination or asset requirement appears. Record the selected master, exact prompt/reference log, dimensions, reviewed geographic scope, integration state and publication evidence. The JSON includes a change log; append meaningful changes rather than silently treating generated art as ready.

Do not render the entire backlog automatically. Brief each new destination or story asset as required, using the [generation template and layout contract](../ONBOARDING_DESTINATION_ART.md).
