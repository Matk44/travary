## How to work here

- **Checks:**

  ```
  dart format --output=none --set-exit-if-changed lib test
  flutter analyze
  flutter test
  npm --prefix functions test
  ```

- **Look at changes in the app:**
  - Build the iOS simulator app with
    `LANG=en_US.UTF-8 flutter build ios --simulator --debug --dart-define=TRAVARY_BACKEND=demo`
    (add `--dart-define=TRAVARY_PREVIEW_ONBOARDING=true` for onboarding),
    then launch `build/ios/iphonesimulator/Runner.app` on the booted
    iPhone 17 Pro.
  - Android: the AVD `Pixel_9_Pro`, with `flutter build apk --debug` plus
    the same defines, then `adb install`.
- **Demo mode** runs Smart Import against the live function (uses real
  Gemini calls). Profile → Design tools has "Preview a different time",
  "Send a test reminder" and "Restart onboarding".
- **Owner preferences:**
  - Commit and push only when asked.
  - Never deploy or publish without a go-ahead.
  - Keep the experience simple and the copy plain.
  - Sell family sharing first and Smart Import last.
  - No free trial, ever.
  - Travi appears sparingly.
