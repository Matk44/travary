# Documents screen concepts

Generated with the built-in ImageGen workflow using the approved Travary Documents, Trips, Today countdown, woven background, and tactile home-navigation references.

Shared prompt contract across all four concepts:

- high-fidelity, shippable portrait mobile UI;
- continuous warm woven linen background;
- navy editorial-serif hierarchy with slate sans-serif metadata;
- cream cotton paper, deckled or perforated edges, printed raster icons, restrained coral/teal/sage/mustard accents;
- the approved five-tab home navigation with Documents raised in petrol teal;
- real Flutter text and interaction will be placed over generated shells;
- no generic Material cards, gradients, glassmorphism, device frame, people, logos, or watermark.

## 01 — Postmarked Ledger

A dense chronological list of separate postal slips. Each row combines a circular date cancellation, wavy postmark, coloured icon stamp, document title, metadata, and chevron. Optimised for fast scanning and straightforward Flutter implementation.

## 02 — Traveller's Folio

An open stitched travel folio with a teal linen spine and dated pockets. Individual document slips visibly peek from each pocket. The most tactile and distinctive option, with more complex responsive slicing and layering.

## 03 — Ticket Timeline

A vertical stitched travel cord connects brass-ring date tags, with individual perforated document tickets attached alongside. Strong chronological storytelling while preserving one-tap access to each document.

## 04 — Destination Dossier

Expandable destination folders group documents by trip. The active trip opens to reveal its document slips; future and past trips remain collapsed with small destination-poster identifiers. Best for accounts containing many trips.
