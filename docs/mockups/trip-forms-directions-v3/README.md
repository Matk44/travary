# Travary refined folio and ledger

Created 5 October 2026 with the built-in ImageGen tool, following feedback that D/E had lost Travary's character.

Both boards retain woven linen, the illustrated postcard and hanging tag, cream paper, navy serif headings, and a navy passport book for document uploads. Manual booking choices and itinerary rows use text rather than a category illustration on every item.

- **A2 — Refined folio:** three simple ticket slips; compact stay preview; text-only manual choices in a 2×2 grid.
- **C2 — Refined ledger:** one journal sheet for the plan; one key-card form instead of a separate preview; text-only booking rows.

Each board contains Trip, Add a booking, Add a stay and Find your flight. Open `REVIEW.html` to compare a board or one screen at a time. The viewer's `linen.png` points to the actual woven app image. Exact prompts and the current brief are in `PROMPTS.md`.

The earlier studies remain in their original folders. Sample data are illustrative; production text and controls must remain live UI.
