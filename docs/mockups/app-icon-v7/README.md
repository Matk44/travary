# Vertical flight ticket colour and style variations

Created with the built-in imagegen tool as edits of [the selected vertical flight coupon](../app-icon-v6/19-vertical-flight-coupon.png). The ticket silhouette, climbing plane, tear-off coupon and diagonal stripe layout were retained while changing the palette and print treatment.

## Variants

- **Night flight:** [1024 px](20-night-flight.png) · [64 px](20-night-flight-64.png) · [32 px](20-night-flight-32.png). Cream aircraft on midnight indigo ticket with orange and brass stripes. Strong dark-storefront contrast and a more atmospheric vintage look.
- **Riso pop:** [1024 px](21-riso-pop.png) · [64 px](21-riso-pop-64.png) · [32 px](21-riso-pop-32.png). Ultramarine plane on lilac paper with tangerine and seafoam stripes. Brighter, playful risograph character.
- **Modernist:** [1024 px](22-modernist.png) · [64 px](22-modernist-64.png) · [32 px](22-modernist-32.png). Ivory plane on vermilion ticket against cobalt. Highest visual contrast at 32 px and the cleanest graphic finish.
- **Heritage green:** [1024 px](23-botanical-heritage.png) · [64 px](23-botanical-heritage-64.png) · [32 px](23-botanical-heritage-32.png). Forest-green aircraft on cotton paper with terracotta and ochre stripes. Warm, quiet heritage print.

All delivered icons are opaque 1024 × 1024 PNGs; the generated 1254 px originals are retained. These are concept assets; launcher files were not changed. Small-size contrast is a visual judgement, not a measured conversion result.
