# Travary travel-object app icon concepts

Generated with the built-in imagegen tool on 1 October 2026. Each concept began as an edit of an existing in-app asset. These are exploratory masters; launcher assets have not been changed.

## Candidates

- **Suitcase badge:** [1024 px](10-suitcase-badge.png) · [64 px](10-suitcase-badge-64.png) · [32 px](10-suitcase-badge-32.png). Source: Nav Trips icon. The most direct link to the app navigation icon, though the mark is familiar.
- **Plane departure:** [1024 px](11-plane-departure.png) · [64 px](11-plane-departure-64.png) · [32 px](11-plane-departure-32.png). Source: Flight icon. The clearest travel signal and strongest small-size contrast.
- **Travel tag:** [1024 px](12-travel-tag.png) · [64 px](12-travel-tag-64.png) · [32 px](12-travel-tag-32.png). Source: Countdown luggage tag. Most aligned with the app's tactile ephemera; the tag and rope add character but have more detail at small size.

All three exports are 1024 × 1024 full-square opaque PNGs. The 1254 px generated sources are retained in this folder. The luggage-tag result received two targeted edits: the rope was brought inside the square and the background was restored to opaque teal. These are visual concepts; none has measured install-conversion results.
