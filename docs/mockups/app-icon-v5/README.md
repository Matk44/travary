# Travary tag + plane variations

Made with the built-in imagegen tool as four edits of [the selected tag concept](../app-icon-v4/12-travel-tag.png). The only fixed idea was a luggage tag with a large, immediately recognisable airplane. Each variation changes the tag, plane art, materials and palette independently of Travary's current in-app theme.

## Concepts

- **Airmail label:** [full icon](13-airmail.png) · [64 px](13-airmail-64.png) · [32 px](13-airmail-32.png). Ivory airmail label, flat cobalt strap, top-view passenger jet and red-blue print stripes. Strong small-size plane read; strap reaches the top edge in the concept master.
- **Leather club:** [full icon](14-leather-club.png) · [64 px](14-leather-club-64.png) · [32 px](14-leather-club-32.png). Oxblood leather tag, propeller aircraft and mustard insignia. More collectible and vintage; the plane is less immediate at 32 px.
- **Pop flight:** [full icon](15-pop-flight.png) · [64 px](15-pop-flight-64.png) · [32 px](15-pop-flight-32.png). Chartreuse silicone tag, violet side-view jet and tangerine background. Strongest small-size contrast and furthest departure from the current brand palette.
- **Canvas flight patch:** [full icon](16-coastal-canvas.png) · [64 px](16-coastal-canvas-64.png) · [32 px](16-coastal-canvas-32.png). Oat canvas, forest-green webbing and front-view aircraft with saffron stripe. Tactile travel-gear feel; the front-view aircraft is less distinct at 32 px.

All delivered icons are opaque 1024 × 1024 square PNGs. The 1254 px generated sources are retained. These are visual explorations; no launcher assets were replaced and conversion has not been measured.
