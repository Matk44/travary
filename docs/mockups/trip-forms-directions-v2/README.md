# Travary trip and forms — clean round

Created 5 October 2026 using the built-in ImageGen tool after feedback that the first round was too busy.

Two directions, each showing the trip, add sheet, stay form and flight finder:

- **D — Postcard light:** one compact colourful destination illustration on the trip; clean typography and simple controls everywhere else.
- **E — Editorial light:** expressive typography with a small destination illustration; the lightest visual treatment.

Open `REVIEW.html` to compare them. The screen selector lets you inspect an individual screen without creating a cropped asset. Exact prompts and UX decisions are in `PROMPTS.md`.

These are concept mockups, with illustrative data. This round changes the visible hierarchy and what is disclosed initially. Application code is not changed.
